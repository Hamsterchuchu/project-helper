# 컴퓨터·프로그램·서버 실습

데스크톱 프로그램 조작, 서버 계산, 기존 실습 결과 재사용이 필요할 때 읽는다. 특정 프로그램이나 운영체제를 필수로 가정하지 않는다.

## 교안에서 실행 범위 추출

작업에 필요한 대상·방법·조건·실행 환경·산출물을 파악한다. 계산 작업이면 기존 결과의 재사용 가능성도 기록한다. 단순 작업에는 불필요한 실행 계획서나 승인 단계를 추가하지 않는다.

| 구분 | 확인할 내용 |
| --- | --- |
| 대상 | 과제에서 지정한 데이터·구조·시료·분석 항목 |
| 방법 | 교안의 명령·코드·프로그램과 필수 설정 |
| 기존 결과 | 원본 위치, 대상·조건 일치 여부, 완료 상태 |
| 실행 자원 | 이미 허용된 실행 범위, 시간·비용·공유 자원 제한 |
| 산출물 | 로그·분석표·그림·보고서 중 요구한 항목 |

교안의 필수 조건과 선택적 예시를 구분한다. 사용자가 교안 재현을 요청했다면 다른 방법을 섞지 않는다. 여러 입력을 생성하는 스크립트는 실행 전에 대상을 확인해 필수 대상만 처리한다.

## 기존 결과 재사용

- 파일 이름만으로 대상이나 조건을 판단하지 말고 실제 입력·출력에서 확인한다.
- 요구한 조건과 일치하는 결과는 재사용한다. 수치와 그림의 출처를 연결하고, 수정 요청 때문에 불필요하게 새 계산을 시작하지 않는다.
- 조건이 다른 결과를 비교할 때 차이를 표시한다. 통일된 조건의 비교처럼 표현하지 않는다.
- 더 강한 주장에 추가 계산이 필요하더라도 그 주장이 과제에 필요한지 먼저 판단한다. 필수 요구와 선택 보완을 구분하고, 사용자가 범위를 줄이면 실제 검증한 범위에 맞게 해석을 조정한다.

## 실행과 검증

- 현재 접근 가능한 컴퓨터·서버·계정이 사용자가 지정한 대상인지 실제로 확인한다. 비밀번호를 채팅이나 공개 파일에 보관하지 않는다.
- 정상 종료 여부와 과학적·분석적 타당성은 따로 확인한다. 분야에 맞는 원본 값·단위·수렴·경고 등 필요한 지표를 본다.
- 교안의 식과 계산 조건을 따른다. 전문적 해석이 불확실하면 일차 자료로 확인하고, 근거 없이 정확성이나 최적성을 단정하지 않는다.
- 대기 중인 작업을 중복 접수하지 않는다. 실패 시 실제 오류를 보고 원인을 좁히고, 변경 없이 같은 고비용 작업을 반복하지 않는다.
- 추가 권한이나 연결 방식의 허용이 필요하면 현재 환경의 승인 절차를 사용한다. 과거 세션의 승인이 새 세션까지 유효하다고 추정하지 않는다.

## 그림과 보존

- 실제 프로그램에서 본 화면이 필요하면 해당 입력·결과를 연 뒤 캡처한다. 이미지 생성이나 재구성 그림을 실행 증거로 쓰지 않는다.
- 화면에는 작업과 관계없는 개인 정보나 인증 정보를 담지 않는다. 편집한 경우 데이터·축·조건을 바꾸지 않고 편집 사실을 필요한 범위에서 밝힌다.
- 표와 그래프는 원본 값으로 만들고 단위·조건·범례를 표시한다. 설명용 그림은 별도로 표시한다.
- 기존 입력과 출력은 보존하고 수정본을 별도로 만든다. 작업 완료 뒤 자신이 시작한 연결이나 프로세스를 정리할 때도 사용자의 다른 작업에 영향이 없는지 확인한다.
