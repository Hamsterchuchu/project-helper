# 사용 예시

아래는 실제 대화에서 추출한 작업 패턴을 바탕으로 **새로 작성한 가상 상황**이다. 실제 과제·기관·계정·데이터·성과를 재현한 자료가 아니며, 결과 안내 예문의 파일도 제공되는 파일이 아니다.

## 예시 1. 브라우저에서 여러 주차 과제 진행

**사용자 요청**

```text
$project-helper
제공한 강의 탭에서 남은 주차별 과제를 정리하고 보고서 작성을 도와줘.
이전 과제의 연구 질문을 이어가되, 각 주차의 교안과 요약 자료를 확인해줘.
제출은 내가 할게.
```

**적용 흐름**

1. 지정된 탭에서 과제별 요구사항을 확인한다.
2. 관련 교안과 별도 요약 자료를 각각 확인한다. 영상의 화면만 본 경우 음성 미확인을 남긴다.
3. 사용자가 허용한 기존 보고서에서 연구 질문을 확인하고 주차별 요구에 맞춰 작성한다.
4. 필수 문항·출처·표시 상태를 대조하고 주차별 파일과 사용자 확인 항목을 전달한다.

**누락을 드러내는 대조표 예시**

| 요구사항 | 근거 | 결과물 | 상태 |
| --- | --- | --- | --- |
| 강의 핵심 요약 | 교안의 실습 안내 | 보고서 첫 절 | 교안 기준 대조 완료 |
| 서로 다른 설계 비교 | 과제 안내의 비교 문항 | 비교표 | 문항 대조 완료 |
| 별도 요약 자료 반영 | 자료 목록의 별도 PDF | 미반영 | 본문 미확인, 검토 초안 유지 |

마지막 행이 남아 있으면 전체 자료를 대조했다고 말하지 않는다. PDF 본문을 읽을 수 있게 된 뒤 필요한 수정을 하고 상태를 갱신한다.

## 예시 2. 지정 실습과 기존 계산 결과

**사용자 요청**

```text
$project-helper
제공한 컴퓨터에서 교안의 분석 실습을 진행해줘.
과제의 필수 대상과 지정 스크립트만 사용하고, 기존 결과가 있으면 재사용해줘.
실제 프로그램 화면과 원본 출력으로 결과를 확인해줘.
```

**적용 흐름**

- 과제에서 지정한 대상과 교안의 선택 예시를 구분한다.
- 스크립트가 만드는 입력 중 필수 대상만 선택한다.
- 기존 결과의 대상·조건·완료 상태가 맞으면 사용한다.
- 필요한 실행만 수행하고 원본 출력에서 값을 확인한다.
- 실제 프로그램 화면을 저장하고 보고서의 수치·단위·그림을 원본과 대조한다.

계산 종료만 확인한 상태라면 “계산은 종료했지만 결과 해석은 아직 확인 중”이라고 구분한다. 원격 연결이 등록되어 있어도 현재 제어 가능한 컴퓨터가 다르면 그 한계를 먼저 알린다.

## 예시 3. 추가 계산 없이 보고서 수정

**사용자 요청**

```text
$project-helper
과제 안내에 맞춰 기존 보고서의 표·그래프와 빠진 설명만 고쳐줘.
원본을 보존하고 기존 계산값을 써줘. 추가 계산은 하지 마.
분석 프로그램의 실제 화면만 그림으로 사용해줘.
```

**적용 흐름**

- 보고서와 과제란을 대조해 수정할 부분을 좁힌다.
- 대상·조건이 맞는 기존 데이터로 표와 그래프를 갱신한다.
- 설명용 이미지가 실행 증거처럼 쓰였으면 실제 캡처로 교체한다.
- 기존 결과가 뒷받침하지 못하는 주장은 줄이고 한계를 적는다. 추가 계산을 시작하지 않는다.
- 수정본의 필요한 전체 페이지와 수치를 확인해 새 버전으로 저장한다.

**가상의 결과 안내 예문**

> 기존 결과를 재사용해 보고서 수정본과 근거 자료를 별도로 저장했습니다. 표·그래프를 원본 데이터와 대조하고 전체 페이지의 표시 상태를 확인했습니다. 추가 계산과 제출은 하지 않았습니다.
>
> 일부 결과는 분석 조건이 달라 비교 해석에 한계가 있습니다. 해당 조건과 본인이 의도한 결론을 확인해 주세요. AI 결과에는 전문적 판단이나 정확성이 부족할 수 있으니, 사용 전에 원자료와 요구사항을 기준으로 항상 직접 확인해야 합니다.

실제 전달 시에는 여기에 실제로 생성·확인한 파일의 링크를 붙인다. 가상의 파일명이나 수행 기록을 사용하지 않는다.

## 예시 4. 목록만 확인하기

**사용자 요청**

```text
$project-helper
제공한 강의 페이지에서 남은 과제와 마감일만 정리해줘.
```

페이지에 표시된 과제명·제출 상태·마감을 정리하고 확인 시점을 남긴다. 보고서 작성, 파일 제출, 계산 실행을 시작하지 않는다. 다른 컴퓨터의 페이지에 접근할 수 없다면 현재 확인하지 못했다고 밝힌다.
