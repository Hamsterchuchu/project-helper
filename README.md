# Project Helper · 과제 도우미

브라우저 탭이나 컴퓨터를 제공받아 **과제 파악 → 지정 절차 수행 → 근거 대조 → 결과물 전달**을 돕는 재사용 가능한 Agent Skill입니다.

An instruction-based skill for completing and checking assignments in a user-provided browser or computer environment. Korean documentation; adaptable to the user's language.

> **AI를 활용한 결과물은 해당 분야의 전문성과 정확성이 부족할 수 있습니다. 제출·공유·실행 전에 사용자가 원자료와 요구사항을 기준으로 결과물을 항상 직접 확인해야 합니다. 이 스킬의 검증 절차도 사용자 검토를 대신하지 않습니다.**

## 어떤 작업에 쓰나요?

- 학습관리시스템의 과제 안내·교안·첨부파일을 읽고 요구사항을 정리할 때.
- 여러 주차의 과제를 나누어 진행하고 누락된 항목을 확인할 때.
- 제공된 프로그램·서버·스크립트로 교안의 실습을 재현할 때.
- 기존 계산이나 분석 결과를 재사용해 보고서를 수정할 때.
- 원본 데이터·실제 화면·최종 문서를 대조하고, 확인하지 못한 부분까지 전달할 때.

단순 개념 질문이나 일반적인 소프트웨어 개발 전체를 다루는 스킬은 아닙니다. 목록 정리만 요청하면 목록 정리까지만 수행합니다.

## 실행 환경

이 저장소에는 **지침과 참고 문서**가 들어 있습니다. 별도 실행 코드, API 키, 계정, 브라우저 드라이버, 컴퓨터 제어 기능은 포함하지 않습니다.

| 작업 | 필요한 환경 |
| --- | --- |
| 브라우저 과제 | 사용자가 허용한 탭에 접근할 수 있는 브라우저 도구 |
| 컴퓨터 실습 | 해당 컴퓨터·프로그램을 실제로 조작할 수 있는 도구 |
| 서버 계산 | 사용자가 허용한 서버 연결과 실행 권한 |
| 문서 생성·검토 | 요청한 파일 형식을 다루고 확인할 수 있는 도구 |

파일만 제공된 환경에서도 자료 분석과 결과물 정리는 할 수 있습니다. 브라우저나 컴퓨터 접근이 없으면 해당 조작은 수행할 수 없습니다. 제공받은 로그인 세션이나 다른 작업자의 탭을 임의로 공유하지 않습니다.

## 설치와 시작

### Codex에서 스킬 폴더 사용

1. 이 저장소를 내려받습니다.
2. `skills/project-helper` 폴더 전체를, 사용하려는 프로젝트의 `.agents/skills/project-helper` 위치에 복사합니다. 이미 같은 이름의 스킬이 있으면 먼저 내용을 비교하고 덮어쓰지 않습니다.
3. 해당 프로젝트를 Codex에서 열고 스킬 목록에서 확인합니다. 목록이 갱신되지 않으면 다시 시작합니다.
4. `$project-helper`를 포함해 아래와 같이 요청합니다.

```text
$project-helper
제공한 브라우저 탭에서 이번 과제 안내와 연결된 자료를 읽어줘.
교안에서 지정한 방법으로 진행하고, 요구사항과 결과물을 대조해줘.
보고서와 근거 파일을 정리해줘. 제출은 내가 할게.
```

개인 스킬 설치를 관리하는 환경에서는 `$skill-installer`에 공개 저장소 주소와 `skills/project-helper` 경로를 지정해 설치를 요청할 수도 있습니다. 실제 설치 위치와 발견 방식은 사용 중인 호스트의 안내를 따릅니다.

### ChatGPT Work 또는 플러그인으로 사용

스킬을 지원하는 환경에서는 등록된 **Project Helper · 과제 도우미**를 선택해 요청합니다. ChatGPT의 스킬 선택은 `@`, Codex의 명시적 호출은 `$project-helper` 형식을 사용할 수 있습니다. 설치·배포 화면은 제품과 계정 설정에 따라 달라질 수 있습니다.

저장소 루트의 `plugin.json`은 같은 스킬을 플러그인으로 묶기 위한 최소 배포 정의입니다. 플러그인 설치를 지원하는 환경에서는 해당 환경의 로컬 등록·설치 절차를 따릅니다. GitHub 공개와 공식 플러그인 디렉터리 등록은 별개의 절차입니다. 일반 채팅에 파일을 첨부하는 것만으로 제어 도구나 설치 기능이 생기지는 않습니다.

설치 위치·호출 방식은 [공식 스킬 안내](https://learn.chatgpt.com/docs/build-skills), 플러그인 등록은 [공식 패키징 안내](https://developers.openai.com/plugins/build/plugins)를 참고하세요.

## 요청에 넣으면 좋은 정보

이미 화면이나 자료에 있는 내용은 다시 적지 않아도 됩니다. 아래 중 결과를 바꾸는 조건만 알려 주세요.

- 작업할 탭·컴퓨터·폴더와 대상 과제.
- 교안을 그대로 따라야 하는지, 사용할 프로그램이나 방법이 지정됐는지.
- 기존에 완료한 계산·보고서와 재사용 가능한 파일.
- 원하는 파일 형식과 저장 위치.
- 추가 자원 사용 제한, 수정 범위, 제출 담당자.

작업 시작 전에 비밀번호를 채팅에 적을 필요는 없습니다. 필요한 인증은 사용 환경이 제공하는 인증 수단으로 진행합니다.

## 사용 예시

### 여러 주차 과제

```text
$project-helper
제공한 강의 페이지에서 미완료 과제를 확인하고 과제별 요구사항을 정리해줘.
완료된 과제는 건드리지 말고, 남은 과제의 보고서 작성을 도와줘.
못 읽은 강의나 자료는 구분해줘. 제출은 내가 할게.
```

### 지정된 실습 재현

```text
$project-helper
제공한 컴퓨터에서 교안의 분석 실습을 진행해줘.
지정된 코드와 조건을 사용하고 기존 결과가 맞으면 재사용해줘.
필수 대상 밖의 추가 계산은 실행하지 말고 필요성을 먼저 설명해줘.
실제 프로그램 화면과 원본 출력으로 결과를 확인해줘.
```

### 기존 보고서 수정

```text
$project-helper
이 보고서를 과제 안내와 대조해서 빠진 부분만 고쳐줘.
원본은 보존하고, 기존 데이터를 재사용해줘.
표와 그래프를 원본과 대조하고 결과물의 전체 페이지도 확인해줘.
검증하지 못한 항목과 내가 확인할 부분을 알려줘.
```

예상 작업 흐름, 가상의 요구사항 대조표, 결과 안내 예문은 [구체적인 예시](skills/project-helper/references/examples.md)에 있습니다. 예시는 실제 과제의 결과나 성과를 입증하는 자료가 아닙니다.

## 동작 원칙

- 과제란·교안·별도 요약·첨부파일을 구분해 확인합니다.
- 실제 수행한 작업과 읽지 못한 자료를 분명히 밝힙니다.
- 요구사항에 맞는 기존 결과를 우선 재사용하고 불필요한 실행을 줄입니다.
- 실제 캡처와 설명용 그림, 계산 결과와 제안한 방법을 구분합니다.
- 완료를 알리기 전에 요구사항·원본 데이터·최종 표시 상태를 대조합니다.
- 사용자 검토가 항상 필요하다는 점과 구체적으로 확인할 항목을 안내합니다.

## 개인정보와 공개 예시

이 스킬은 과제 수행 대화에서 나타난 작업 패턴을 일반화해 만들었습니다. 공개 파일에는 대화 원문, 실제 보고서, 개인 이름·학번, 기관 내부 주소, 계정·호스트, 개인 경로, 인증·세션 링크를 포함하지 않습니다. 예시는 새로 작성한 가상 상황입니다. 제작 방식은 Codex-assisted입니다.

사용자가 자신의 과제에 필요한 이름 등을 결과물에 넣도록 요청하는 것과, 공개 저장소에 그 자료를 넣는 것은 별개입니다. 이 저장소를 사용한 실제 작업 기록과 결과물은 공개 소스 폴더 밖에 보관하세요. `.gitignore`는 보조 장치이며 모든 개인정보 노출을 막아주지는 않습니다.

## GitHub에 올리기

1. GitHub에 새 저장소를 만들고, 이 폴더 **안의 파일과 폴더**를 저장소 루트에 올립니다. `.gitignore`도 포함합니다.
2. 아래 구조에서 `README.md`, `plugin.json`, `skills/project-helper/SKILL.md`가 있는지 확인합니다.
3. 실제 과제 자료·화면·인증 파일·작업 기록을 추가하지 않았는지 변경 내용을 확인합니다.
